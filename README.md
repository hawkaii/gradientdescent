# Gradient Descent

A product for every hobby. Software, content and audience, built whole.

Live: https://gradientdescent.wiki (pending deploy)

## Stack

- Astro 7 (static output)
- Monocraft (pixel font) + Inter
- Palette: `#141414` ground · `#FF2FA0` pink · `#E6FF02` lime

## Dev

```bash
npm install
npm run dev      # localhost:4321
npm run build    # static output in dist/
```

Requires Node >= 22.23.4. On this machine, use `/tmp/opencode/node/node-v22.23.4-linux-arm64/bin`.

## Products

Products live in `src/content/products/*.md`. Adding a product is one file plus one screenshot.
